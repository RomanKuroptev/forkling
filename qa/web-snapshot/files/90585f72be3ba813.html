Arbitrary memory emulation

From Esolang
Jump to navigation Jump to search

Arbitrary memory emulation is a method of encoding memory which, given a value that can be infinite in size without precision loss, allows for arbitrary memory in the event that such is not possible normally. AME can be used to emulate flat data structures like stacks, tapes, and arrays, and with modifications can encode more complex structures.

Structure

Additive AME

Let 𝐴 be the value which will be used for aAME. We define a positive integer 𝑆 greater than 1 which will denote the maximum size of each "cell" in memory, where a cell can have an integer value of [0, 𝑆). The index of each cell is denoted as 𝑖. The relative position of each cell in memory, denoted by 𝑥, is 𝑆𝑖, where dividing 𝐴 by 𝑥 and applying that modulo 𝑆 results in the cell's value in memory, and multiplying any value 𝑣 by 𝑥 results in its relative value. Each cell is 𝑆 times higher than the previous one.

Turing-completeness

A typical requirement for Turing-completeness is that the language has access to unbounded memory, regardless of the size of each cell. AME "flips" this case, where values of infinite size can be used for computational power, regardless of how many memory addresses there actually are. However, this requires that the language is able to handle values of infinite size without precision loss, and the language has the necessary space in order to compute and thereafter process and transform the memory.

In order for a target language to implement AME of either form, it must be able to calculate multiplication, division, and perform some sort of equality check against zero.

Variations

Payload-flag model (aAME)

A variation assigns a fixed length to each cell, reserving the last bit to continue the value into the next cell, allowing an unbounded size for each cell.

Each cell is split into a payload of size 𝑃 and a flag of size 𝐹, both greater than one. The size of the flag determines how many unique states it has (e.g. 𝐹 = 2 for two distinct states). The true size of each cell, holding both the payload and flag, is 𝑃𝐹. To extract the payload and flag from a cell, the formulae P value = v   m o d   P {\displaystyle P_{\text{value}}=v\ \mathrm {mod} \ P} and F value = ⌊ v P ⌋ {\displaystyle F_{\text{value}}=\left\lfloor {\frac {v}{P}}\right\rfloor } are used respectively.

Usage

  • Countable uses aAME to process I/O.
  • FRACTRAN uses mAME to simulate counter machines
  • Funciton uses aAME to process strings and arrays.
  • Iterate programs use aAME to emulate stacks and deques.
  • JOMP uses mAME to emulate a Minsky machine.
  • Laconic and NQL programs use aAME to emulate stacks using natural numbers.
  • The section 14.2 Minsky machine uses mAME.
