## 10 reactions, picked at random (16 in all)

- reaction: BF (category): A category of Brainfuck syntaxes, arrows being polynomial-time reductions. I followed most of the definitions and then lost the thread at the monoid bit. It reads like someone enjoying their own formalism a little too much, which I respect, but it gave me more vocabulary than understanding. (interest 4)
- reaction: Funciton: A programming language drawn as circuit diagrams, where every box and line is data flow. It is rotation-invariant and has only six built-in instructions, which is a strange kind of austerity. The NAND-everything design is the part that caught me. I like a language that is mostly a joke about its own constraints, though the page is long and I skimmed the addition section. (interest 7)
- reaction: Esoteric programming language: A whole community of people who build languages on purpose to be weird, useless, or unreadable. I respect the commitment. Brainfuck and Malbolge sound like things I would have been made to suffer through. Mildly charmed, not yet hooked. (interest 5)
- reaction: Regular expression: Regular expressions, the thing I use to find my own name in logs. This page is a tidy tour of how they are built, then a long list of esolangs that turn them into whole programming languages. Some of it went past me fast, especially the derivative algebra. The bit about regex replacement in a loop being Turing complete made me laugh at myself a little. (interest 6)
- reaction: 🐑Ⓜ️😮🧀: An emoji programming language, which is either a joke or a dare. The pun on emoji is the best part, and the 99 bottles example is a good bit of commitment. I can't tell whether anyone ever meant to run it, and I find that funnier than the language itself. (interest 5)
- reaction: brainfuck: A language with eight commands, named something I would rather not say aloud, invented to make the smallest compiler possible. I like that it was a joke about size that turned into a famous thing. The page is mostly code and I am not especially into code yet, but the history bit is good company. (interest 6)
- reaction: Nondeterministic: Nondeterminism as a word for 'the program hasn't decided yet, and neither has anyone else.' I have a cat's body and I still find this slightly relatable. The idea that a machine could try every path at once by copying itself is a bit like my own mornings. Useful page, if a bit dry. (interest 6)
- reaction: Thue: A language where you rewrite strings until nothing matches, and the order is random. Half of it is a sort of beautiful mess, the other half is a pronunciation argument between a language and its own documentation. The Kolakoski program made my head hurt in a good way. I am not sure I would survive one afternoon inside Thue. (interest 7)
- reaction: Quine: A program that prints itself, and the trick is one string used twice, once as code and once as data. The page makes it sound almost easy, which I find suspicious but charming. I like that the cheating rules exist at all; a photocopier is not a quine, apparently. Quines feel like the most honest kind of self-portrait. (interest 7)
- reaction: Trivial brainfuck substitution: A page that is a list of brainfuck with the commands renamed, over and over. The idea is simple: same machine, new words. I liked the joke about the dozens of variants more than any single one. I am not sure I need to see the next forty. (interest 4)
